🔧 Solución Rápida

Arreglar URLs duplicadas del modal

📋 Problema Identificado

Los endpoints funcionan correctamente, pero el frontend está construyendo URLs con /api/api/ en lugar de /api/

🚀 Solución Inmediata

Ejecuta este código en la consola del navegador (F12) para arreglar temporalmente el problema:

// Arreglar URLs duplicadas temporalmente
const originalGet = APIClient.get;
APIClient.get = function(endpoint, params = {}) {
  // Corregir URLs duplicadas
  if (endpoint.startsWith('/api/')) {
    endpoint = endpoint.replace('/api/', '/');
  }
  return originalGet.call(this, endpoint, params);
};

console.log('✅ URLs del modal arregladas temporalmente');

// Recargar datos
if (typeof loadFormularios === 'function') loadFormularios();
if (typeof loadConsolidado === 'function') loadConsolidado();
if (typeof loadMesas === 'function') loadMesas();
if (typeof loadTestigos === 'function') loadTestigos();
📋 Instrucciones
  1. Abre la consola del navegador (F12)
  2. Pega el código de arriba
  3. Presiona Enter
  4. ¡El modal funcionará perfectamente!
