🔧 Solución Error 404

Modal de Validación - Coordinador de Puesto

Problema identificado: El error 404 es causado por un problema de autenticación. El modal está completamente funcional, pero necesitas estar logueado con el usuario correcto.
1
Cerrar Sesión Actual

Primero, cierra la sesión actual para limpiar cualquier token incorrecto.

Opción A: Usar el botón "Cerrar Sesión" en el dashboard
Opción B: Limpiar manualmente en consola del navegador (F12):
localStorage.clear();
window.location.href = '/auth/login';
2
Iniciar Sesión con Usuario Correcto

Usa las credenciales del coordinador de puesto que acabamos de crear:

📋 Credenciales de Prueba:
Usuario: COORD_PUESTO_TEST
Cédula: 99999999
Contraseña: test123
URL: http://localhost:5000/auth/login
3
Verificar Autenticación Correcta

Después del login, verifica en la consola del navegador (F12):

console.log('Usuario:', JSON.parse(localStorage.getItem('user_data') || '{}'));
✅ Resultado esperado:
{rol: "coordinador_puesto", nombre: "COORD_PUESTO_TEST"}
4
Navegar al Dashboard Correcto

Ve al dashboard del coordinador de puesto:

URL: http://localhost:5000/coordinador/puesto

Nota: NO uses el dashboard del testigo. Debe ser específicamente el dashboard del coordinador.

5
Probar el Modal

Ahora busca el formulario en la tabla y haz clic en el botón "Ver" (ojo).

🎯 Resultado esperado:
• Modal se abre sin errores
• Se muestra la imagen del formulario E-14
• Aparece tabla detallada de candidatos
• Se ven validaciones automáticas
• Controles de zoom funcionan
