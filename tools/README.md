# Tools Directory

This directory contains all utility scripts organized by category:

- **admin/**: Administrative and analysis tools
- **verification/**: System verification and validation scripts  
- **correction/**: Data correction and fix scripts
- **data_loading/**: Data import and loading utilities
- **analysis/**: Data analysis and cleanup tools
- **server/**: Server startup and management scripts

## Usage

Run scripts from the project root directory:
```bash
python tools/verification/verificacion_rapida_sistema.py
```
