# Admin Tools

Administrative and system analysis tools:

- `analizar_coordinadores.py` - Analyze coordinator data
- `diagnosticar_coordinadores.py` - Diagnose coordinator issues
- `encontrar_ubicaciones_validas.py` - Find valid locations
- `mostrar_puestos_con_coordinadores.py` - Show polling stations with coordinators
- `resumen_sistema.py` - System summary report
