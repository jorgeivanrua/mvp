# Verification Tools

System verification and validation scripts:

- `verificacion_rapida_sistema.py` - Quick system check
- `verificacion_completa_todos_roles.py` - Complete role verification
- `verificar_credenciales_simple.py` - Check login credentials
- `verificar_sistema_completo.py` - Full system verification

## Quick Start
```bash
# Quick system check
python tools/verification/verificacion_rapida_sistema.py

# Complete verification
python tools/verification/verificacion_completa_todos_roles.py
```
